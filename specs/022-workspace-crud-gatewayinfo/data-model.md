# Data Model: Workspace CRUD, GatewayInfo & GetCurrentUser

## Entities

### Workspace

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| ID | string | ObjectMeta.id | Unique identifier |
| Name | string | ObjectMeta.name | DNS-1123 label |
| CreatedAt | time.Time | ObjectMeta.created_at_ms | Millisecond epoch |
| Labels | map[string]string | ObjectMeta.labels | Deep copied |
| Annotations | map[string]string | ObjectMeta.annotations | Deep copied |
| ResourceVersion | uint64 | ObjectMeta.resource_version | Optimistic concurrency |
| Workspace | string | ObjectMeta.workspace | Unused for Workspace entity |
| DeletionTimestamp | *time.Time | ObjectMeta.deletion_timestamp_ms | Nil if not deleting |
| Phase | WorkspacePhase | WorkspaceStatus.phase | Active, Terminating |

Proto source: `datamodelv1.Workspace` (ObjectMeta + WorkspaceStatus)

### WorkspaceMember

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| ID | string | ObjectMeta.id | Unique identifier |
| Name | string | ObjectMeta.name | Auto-generated by gateway |
| CreatedAt | time.Time | ObjectMeta.created_at_ms | Millisecond epoch |
| Labels | map[string]string | ObjectMeta.labels | Deep copied |
| Annotations | map[string]string | ObjectMeta.annotations | Deep copied |
| ResourceVersion | uint64 | ObjectMeta.resource_version | Optimistic concurrency |
| PrincipalSubject | string | principal_subject | OIDC sub claim |
| Role | WorkspaceRole | role | Admin or User |

Proto source: `openshellv1.WorkspaceMember` (ObjectMeta + PrincipalSubject + WorkspaceRole)

### WorkspacePhase (enum, string)

| Value | Proto | Meaning |
|-------|-------|---------|
| WorkspaceActive | WORKSPACE_PHASE_ACTIVE | Normal operation |
| WorkspaceTerminating | WORKSPACE_PHASE_TERMINATING | Being deleted |
| WorkspaceUnknown | WORKSPACE_PHASE_UNSPECIFIED | Unknown/default |

Pattern: matches `SandboxPhase` (string const type).

### WorkspaceRole (enum, string)

| Value | Proto | Meaning |
|-------|-------|---------|
| WorkspaceRoleAdmin | WORKSPACE_ROLE_ADMIN | Workspace admin |
| WorkspaceRoleUser | WORKSPACE_ROLE_USER | Regular user |

Pattern: `type WorkspaceRole string` with named constants.

### GatewayInfo

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| Status | ServiceStatus | GetGatewayInfoResponse.status | Healthy/Degraded/Unhealthy |
| Version | string | GetGatewayInfoResponse.gateway_version | Binary version |
| ComputeDrivers | []ComputeDriverInfo | GetGatewayInfoResponse.compute_drivers | Deep copied slice |

Proto source: `openshellv1.GetGatewayInfoResponse` (flat response, no wrapper)

### ServiceStatus (enum, string)

| Value | Proto | Meaning |
|-------|-------|---------|
| ServiceStatusHealthy | SERVICE_STATUS_HEALTHY | Gateway healthy |
| ServiceStatusDegraded | SERVICE_STATUS_DEGRADED | Partially available |
| ServiceStatusUnhealthy | SERVICE_STATUS_UNHEALTHY | Gateway down |
| ServiceStatusUnknown | SERVICE_STATUS_UNSPECIFIED | Unknown |

### ComputeDriverInfo

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| Name | string | ComputeDriverInfo.name | Gateway-assigned driver name |
| DriverName | string | ComputeDriverCapabilities.driver_name | Driver-reported name |
| DriverVersion | string | ComputeDriverCapabilities.driver_version | Driver-reported version |

Proto source: `openshellv1.ComputeDriverInfo` (flattened from nested Capabilities)

### CurrentUser

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| Subject | string | GetCurrentUserResponse.subject | OIDC sub claim |
| DisplayName | string | GetCurrentUserResponse.display_name | Human-readable name |
| Roles | []string | GetCurrentUserResponse.roles | Deep copied |
| Scopes | []string | GetCurrentUserResponse.scopes | Deep copied |
| IdentityProvider | string | GetCurrentUserResponse.identity_provider | Auth provider name |

Proto source: `openshellv1.GetCurrentUserResponse` (flat response, no wrapper)

## Relationships

- Workspace 1:N WorkspaceMember (workspace name is the join key)
- GatewayInfo 1:N ComputeDriverInfo
- CurrentUser is standalone (no entity relationships)

## Validation Rules

| Operation | Validation |
|-----------|-----------|
| CreateWorkspace | name non-empty |
| GetWorkspace | name non-empty |
| DeleteWorkspace | name non-empty |
| AddWorkspaceMember | workspace non-empty, principalSubject non-empty, role valid (Admin or User) |
| RemoveWorkspaceMember | workspace non-empty, principalSubject non-empty |
| ListWorkspaceMembers | workspace non-empty |
| ListWorkspaces | no required validation (all fields optional) |
| GetGatewayInfo | no required validation |
| GetCurrentUser | no required validation |
