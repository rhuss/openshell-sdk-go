# Implementation Plan: Add Workspace Scoping to All RPCs

**Branch**: `021-workspace-scoping` | **Date**: 2026-07-31 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/021-workspace-scoping/spec.md`

## Summary

Add a `workspace string` parameter as the first argument after `ctx` to every workspace-scoped sub-client method. All 28 proto Request messages already have `workspace` fields that the SDK is not populating. This change makes the SDK a complete replacement for the dashboard BFF's direct gateway calls. The fake client gains workspace isolation via composite store keys, and `ListOptions` gains an `AllWorkspaces` field for cross-workspace listing.
