# Implementation Plan: Local Port Listener

**Branch**: `014-local-port-listener` | **Date**: 2026-06-30 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/014-local-port-listener/spec.md`

## Summary

Add a `Listen` method to `TCPInterface` that binds a local TCP port and tunnels every accepted connection to a specified sandbox port, returning a standard `net.Listener`. This reuses the existing `Forward()` and `Tunnel()` plumbing internally, providing `ssh -L` style port forwarding with a single method call.
